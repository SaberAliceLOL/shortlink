## 面试素材积累（本周可讲的三个故事）

1. **号段发号器为什么不用 Redis INCR** —— Redis 持久化异步，宕机回吐号段会重号；
   号段落 MySQL 强一致，且 DB 压力被号段摊薄。
2. **off-by-one + 哨兵值两个 bug** —— 都是单测逮出来的，说明"自己实现的组件必须有测试"。
3. **CI 失败两次的排查过程** —— 从"本地绿"到"CI 红"的定位思路：先怀疑环境差异，
   再发现架构缺陷（模块级实例绕过 DI）。这个反思比修 bug 本身更值钱。
